# Происхождение скриншотов

[← К проекту](../../README.md)

Изображения скопированы без изменения содержимого. Они сняты в одноразовом CI-окружении без авторизованного Telegram-аккаунта. Личной переписки, номера пользователя и кода входа на них нет.

- **Android, новая палитра:** APK [34156952657](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34156952657), снимки [34159878677](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34159878677). Установка, стартовые сценарии и переключение тем прошли; 12 ключевых снимков проверены. Индикатор страниц соответствует палитре. Предыдущая попытка [34158944393](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34158944393) не открыла список приложений системного лаунчера. После однократного восстановления лаунчера новый тест проверил видимый значок, открытие клиента по нему и все стартовые сценарии; APK не изменялся.
- **Windows, прежнее оформление:** EXE [34031740962](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34031740962), снимки [34059187270](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34059187270). Сборка с новым стилем ещё выполняется.

Снимки показывают стартовые экраны и пустую форму номера. Они не доказывают работу заметок, шаблонов, «нечиталки» или окончательный вид переписки после входа. Контрольные суммы: [provenance.json](provenance.json).

## Светлая и тёмная темы Windows

Оба опубликованных Windows-снимка относятся к светлой теме. Зелёный верх стартового экрана — отдельная декоративная шапка предыдущего оформления. Он не означает, что весь клиент работает в тёмной теме. Проверка новой версии будет включать обе темы и переход к пустой форме номера.

## Внутренние экраны

Пока не опубликованы. Для них нужны реальные снимки работающего клиента с вымышленными демонстрационными чатами. Имена, аватары, переписка, уведомления и номера реальных пользователей в публичную галерею не включаются. Каждый снимок должен указывать платформу, тему и точную сборку; демонстрационные данные будут явно обозначены.
