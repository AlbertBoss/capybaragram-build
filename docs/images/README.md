# Скриншоты текущих сборок

[← К проекту](../../README.md)

Изображения скопированы без изменения содержимого. Они сняты в одноразовом CI-окружении без авторизованного Telegram-аккаунта. На них нет переписок, номера пользователя или кода входа. Открыты стартовые экраны и пустая форма номера.

- Android: APK из [34058353588](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34058353588); снимки из [34059939947](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34059939947). В этом тесте не удалось открыть список приложений Pixel; последующая проверка того же APK [34060394953](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34060394953) прошла.
- Windows: Release EXE из [34031740962](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34031740962); снимки из [34059187270](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34059187270).

Скриншоты не доказывают работу заметок, шаблонов или «нечиталки» после входа. Они показывают фактический текущий интерфейс; окончательный дизайн ещё разрабатывается. Контрольные суммы сохранены в [provenance.json](provenance.json).
