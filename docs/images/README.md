# Происхождение скриншотов

[← К проекту](../../README.md)

Изображения скопированы без изменения содержимого. Они сняты в одноразовом CI-окружении без авторизованного Telegram-аккаунта. Личной переписки, номера пользователя и кода входа на них нет.

- **Android, новая палитра:** APK [34154803384](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34154803384), снимки [34156405310](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34156405310). Установка, стартовые сценарии и переключение тем прошли; все 16 снимков проверены. Синяя точка текущей страницы ещё видна на этих снимках; её исправление проходит отдельную сборку.
- **Windows, прежнее оформление:** EXE [34031740962](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34031740962), снимки [34059187270](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34059187270). Сборка с новым стилем ещё выполняется.

Снимки показывают стартовые экраны и пустую форму номера. Они не доказывают работу заметок, шаблонов, «нечиталки» или окончательный вид переписки после входа. Контрольные суммы: [provenance.json](provenance.json).
