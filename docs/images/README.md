# Происхождение скриншотов

[← К проекту](../../README.md)

Изображения скопированы без изменения содержимого. Опубликованные стартовые экраны сняты в одноразовом CI-окружении без авторизованного Telegram-аккаунта. Личной переписки, номера пользователя и кода входа на них нет.

- **Android, новая палитра:** APK [34156952657](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34156952657), снимки [34159878677](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34159878677). Установка, стартовые сценарии и переключение тем прошли; 12 ключевых снимков проверены. Индикатор страниц соответствует палитре. Предыдущая попытка [34158944393](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34158944393) не открыла список приложений системного лаунчера. После однократного восстановления лаунчера новый тест проверил видимый значок, открытие клиента по нему и все стартовые сценарии; APK не изменялся.
- **Windows, новая палитра:** EXE [37070585321](https://github.com/AlbertBoss/capybaragram-build/actions/runs/37070585321), снимки [37155302094](https://github.com/AlbertBoss/capybaragram-build/actions/runs/37155302094). Проверены обе темы и переход к пустой форме номера. Четыре снимка просмотрены; они скопированы побайтово, без ретуши интерфейса, курсора или постороннего рабочего стола.

Снимки показывают запуск и пустую форму номера. Они не доказывают работу заметок, шаблонов, «нечиталки» или готовность нового оформления переписки. Контрольные суммы: [provenance.json](provenance.json).

## Светлая и тёмная темы Windows

Опубликованы стартовый экран и пустая форма номера в каждой из двух тем. В тёмной теме графитовый фон сохраняется после перехода к вводу номера; в светлой используется тёплый оттенок бумаги. Проверка цвета выполнена по фактическим пикселям формы, а не только по выбранной настройке темы.

## Внутренние экраны

Снимки предыдущего Windows-интерфейса с видимым курсором удалены из текущей галереи. Новые кадры должны показывать проверенную сборку с актуальным оформлением и только вымышленные демонстрационные данные. До такой проверки внутренний дизайн не считается принятым.
