# Происхождение скриншотов

[← К проекту](../../README.md)

Изображения скопированы без изменения содержимого. Стартовые экраны сняты в одноразовом CI-окружении без авторизованного Telegram-аккаунта. Два внутренних Windows-экрана сняты локально в тестовом аккаунте с вымышленными демонстрационными каналами. Личной переписки, реальных имён и аватаров, номера пользователя и кода входа на них нет.

- **Android, новая палитра:** APK [34156952657](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34156952657), снимки [34159878677](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34159878677). Установка, стартовые сценарии и переключение тем прошли; 12 ключевых снимков проверены. Индикатор страниц соответствует палитре. Предыдущая попытка [34158944393](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34158944393) не открыла список приложений системного лаунчера. После однократного восстановления лаунчера новый тест проверил видимый значок, открытие клиента по нему и все стартовые сценарии; APK не изменялся.
- **Windows, прежнее оформление:** EXE [34031740962](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34031740962), снимки [34059187270](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34059187270). Сборка с новым стилем ещё выполняется.

Стартовые снимки показывают запуск и пустую форму номера. Внутренние снимки показывают демонстрационный канал и ввод текста в редактор заметки. Они не доказывают сохранение заметок, работу шаблонов, «нечиталки» или окончательный вид нового оформления. Контрольные суммы: [provenance.json](provenance.json).

## Светлая и тёмная темы Windows

Оба опубликованных Windows-снимка относятся к светлой теме. Зелёный верх стартового экрана — отдельная декоративная шапка предыдущего оформления. Он не означает, что весь клиент работает в тёмной теме. Проверка новой версии будет включать обе темы и переход к пустой форме номера.

## Внутренние экраны

`windows-demo-chat.png` и `windows-demo-note.png` — реальные снимки локального Windows EXE из сборки [34031740962](https://github.com/AlbertBoss/capybaragram-build/actions/runs/34031740962), светлая тема прежнего оформления. Захвачено только окно приложения через Alt+Print; пиксели не редактировались. Все видимые каналы и тексты созданы для демонстрации.

На втором снимке текст введён в редактор локальной заметки. Проверка сохранения и повторного открытия ещё не завершена. Присутствующая за редактором плашка Telegram относится к недавно добавленному демонстрационному каналу. Новая Windows-палитра и внутренние Android-сценарии этими снимками не подтверждаются.
