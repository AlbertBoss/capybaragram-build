# Исходники текущих кандидатов

Комплект обновлён 4 октября 2026 года для Android-сборки
[37201227437](https://github.com/AlbertBoss/capybaragram-build/actions/runs/37201227437)
и Windows-сборки
[37201211653](https://github.com/AlbertBoss/capybaragram-build/actions/runs/37201211653).
Android APK собран; Windows в момент упаковки ещё компилируется. Полная
пользовательская приёмка этих кандидатов не завершена.

Архивы пока подготовлены локально и не опубликованы как окончательный релиз.
Точный публичный код можно изучить по закреплённым ссылкам ниже.

## Дополнение сетевого модуля Android

`CapybaraGram-Android-Connection-DependencySources.zip`, 8 174 585 байт.
SHA-256: `30ba1b1e94002f2a36605ccb325be676fef0c97436d2db1dd0ab5254a97b888b`.

Сохранены оригинальные исходные `.crate`-архивы 70 normal/build-зависимостей,
перечисленных в уведомлениях настоящего ARM64 APK. Их SHA-256 совпали с
замороженным `ci/android-connection/Cargo.lock`. Проверена структура архивов
с 3 779 файлами и сверены 138 файлов уведомлений с текстом внутри APK.

Выбор сделан по уведомлениям конкретного APK, а не по всем 111 записям lock.
В комплект также включены точный lock и `CONNECTION-NOTICES.txt` APK.
Код зависимостей, Cargo и build scripts при получении материалов не запускались.
Правила реестра и смысл контрольной суммы сверены с
[официальной документацией Cargo](https://doc.rust-lang.org/cargo/reference/registry-index.html).

## Что ещё требуется для итоговой поставки

Исходные архивы GitHub не включают содержимое подмодулей. Их закреплённые
версии сохранены в манифесте, но для сборки нужен рекурсивный checkout.
Инструменты, другие Gradle/CMake-зависимости и веса модели речи находятся
отдельно. Это комплект исходных снимков, а не готовая офлайн-среда.

Ранее подготовленные дополнения Android/Windows описывают старые проверки
зависимостей. Они ещё не сверены как полный фактический состав этих кандидатов.
Windows использует другой граф Rust; Android-дополнение его не заменяет.
Полнота соответствующих исходников всего клиента, окончательные уведомления
и совместимость условий компонентов требуют отдельной проверки перед релизом.

API-параметры владельца, ключи подписи и Telegram-профили в комплект не входят.
MIT-лицензия оригинальных вспомогательных материалов CapybaraGram сохраняется
рядом с исходниками; она не заменяет условия Telegram и сторонних компонентов.

Порядок подготовки модулей и текущие открытые вопросы описаны в
[техническом руководстве](DEVELOPER-GUIDE.md). Проверка хешей подтверждает
происхождение файлов; она не подтверждает работоспособность всех функций
или отсутствие всех уязвимостей.

## Проверка нового APK в эмуляторе

Новый ручной workflow `Android current candidate runtime` проверяет именно
APK 37201227437 по SHA-256 и подписи. Он устанавливает его в отдельный
API 30 эмулятор с трансляцией ARM64, открывает светлую/тёмную заставку и
форму входа, проверяет окно подключения, запуск/отключение локального
встроенного маршрута и перезапуск приложения.

В этом тесте не вводятся телефон, пароль, код и данные аккаунта. Проверка
локального маршрута не означает успешное соединение с Telegram у реального
провайдера. API 30 не подтверждает аппаратный callback скриншота Android 14.
Проверка [37206837396](https://github.com/AlbertBoss/capybaragram-build/actions/runs/37206837396)
успешно выполнила эти сценарии на настоящем APK 37201227437. Подтверждены
установка, запуск, обе смены темы, форма входа без ввода телефона, запуск
производственной ARM64-библиотеки через JNI, её локальная готовность,
явное отключение маршрута и перезапуск. Реальная доступность Telegram
через встроенный маршрут и сохранение авторизации этим не проверялись.

Просмотрены все 12 снимков. В окне подключения на экране шириной 320dp длинное
описание уходит ниже начальной видимой области. Подготовлены более короткие
русские/английские тексты и подпись кнопки; новая сборка и проверка отображения
исправления ещё требуются. Успех функционального теста не снимает этот недочёт.

## Сетевые зависимости Windows

Ручной workflow `Windows connection source inventory` получает отдельный
замороженный граф сетевого ядра на Windows с Rust 1.88.0. Все 24 файла ядра и
17 подготовленных исходников должны совпасть с входами производственной
библиотеки. Он сохраняет выбранные normal/build-архивы `.crate`, оригинальные
уведомления, lock и манифест; клиент и build scripts библиотек не запускаются.

Локально проверены отказы при несовпадении SHA-256, обходе путей, ссылках,
повторном файле, неверном имени пакета и выходящем за архив пути лицензии.
Результат настоящей Windows-инвентаризации ещё не получен. Метаданные Cargo
могут объединять дополнительные development features; полученный набор
сохраняет источники с запасом и не считается точным списком того, что
статически включено в EXE. Полный состав программы проверяется отдельно.
