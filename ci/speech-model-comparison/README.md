# Две модели на одних и тех же русских записях

Предыдущая серия с настоящим JNI из APK дала текст, но Tiny в режиме `auto`
получила WER 33,3% на пяти заранее выбранных телефонных записях. Это не принятое
качество. Здесь сравниваются нынешняя **Tiny** и **Base Q5_1** на тех же первых
пяти строках MInDS-14. Обе получают одинаковый язык `ru`, одинаковый Opus/декодер
и неизменённую ARM64 JNI из подписанной APK 37208052043. Десять случаев заданы
до получения ответов; не выбираются только удачные записи.

Модели — из [закреплённой версии репозитория автора whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp/tree/5359861c739e955e79d9a303bcbc70fb988958b1).
В `model-choices.json` сохранены точные размеры и LFS SHA-256: Tiny 77 691 713 байт,
Base Q5_1 59 707 625 байт. Сжатая Base меньше по файлу, но её скорость и точность
не обещаются до измерения. [Поддержка квантования](https://github.com/ggml-org/whisper.cpp#quantization)
не доказывает, что эта модель лучше на русском.

Модели загружаются только в одноразовое CI-окружение и проверяются по размеру и
SHA-256. Полученные файлы весов не исполняются как Python/Pickle-код. Отдельный
Android-помощник не имеет Internet, аккаунта Telegram и доступа к профилям
владельца. Он проверяет данные assets перед распознаванием. Движок берётся из
APK, а не пересобирается специально для этого сравнения; модель приложения и
его интерфейс пока не меняются. Сеть нужна хосту только для подготовки.

Результаты содержат все десять ответов, эталоны, WER и длительность обработки.
Каждый готовый ответ выводится сразу; тайм-аут сохраняет частичные наблюдения и
диагностику. Предел десяти вызовов — 2400 секунд, всего задания — 50 минут.
`TECHNICAL_PASS` означает выполнение обоих вариантов, а не заданный уровень
качества. Применение модели будет отдельным изменением после оценки ответов.
Android 11 с трансляцией ARM64 не показывает скорость физического телефона.
Пять записей также не доказывают качество всех голосовых и работу меню клиента.

Аудио и эталоны используются из [прежнего пакета](../speech-ru/README.md):
полное авторство, CC BY 4.0, неизменённый выбор строк и преобразования сохранены.
